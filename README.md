# Fake News Detection Using Machine Learning (MVP Architecture)

A web application that classifies news articles as **Real** or **Fake** using Machine Learning and Natural Language Processing (NLP). Designed cleanly using the Model-View-Presenter (MVP) pattern.

## Architecture

- **Model**: Responsible for loading data, NLP preprocessing, model training, persistence, and inference.
- **Presenter**: Responsible for handling request orchestration, input validation, invoking model logic, and formatting responses for the View.
- **View**: Front-end user interface (HTML5, CSS3, JS, Bootstrap 5) displaying forms, loading states, and prediction results. Views do not interact directly with ML models.
